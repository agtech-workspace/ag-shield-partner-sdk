PARTNER INTEGRATION PREVIEW

Server-side API integration

Build safer payment workflows with AG-SHIELD risk indicators.

A TypeScript SDK for approved partners to call AG-SHIELD's risk assessment endpoint. Responses are indicators requiring review, not proof of guilt or a guarantee that a transaction is safe.

01   Get access

Request an authorized tenant API key with verify:read. Keep it in your backend secret store.

02   Integrate

Install the package from the dedicated partner GitHub repository and call riskCheck from Node.js 22+.

03   Verify

Use a consented live smoke test before processing real partner requests. Failed checks mean UNKNOWN, not safe.

Backend usage

import { AGShieldClient } from '@ag-tech/shield-sdk'

const shield = new AGShieldClient({
  apiKey: process.env.AG_SHIELD_API_KEY,
  baseUrl: process.env.AG_SHIELD_BASE_URL
})

const result = await shield.riskCheck({
  account_number: process.env.AUTHORIZED_ACCOUNT_NUMBER,
  bank_name: process.env.AUTHORIZED_BANK_NAME
})

// Use only as an indicator in a reviewed decision policy.
console.log(result.recommended_action)

This server-side example takes authorized data from environment variables. The documentation website URL is not the API base URL.

Preview limitations: AG-SHIELD is an early-stage service. Gateway requests may fail because of authorization, coverage, quotas, upstream providers or temporary downtime. Never interpret a low score or a failed request as proof of safety. The partner SDK currently exposes riskCheck() only; account-name resolution is a separate website capability and is not part of this SDK. Live availability and accuracy have not been independently certified.
