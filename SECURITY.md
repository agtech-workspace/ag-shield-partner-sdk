# Security

Never disclose API keys or bank customer data in issues, screenshots, requests, browser code, or public commits.

Report security issues privately to AG Tech using its authorized contact channel (agtechrelations@gmail.com). Do not include credentials or full bank-account identifiers in the initial report.

This partner SDK contains NO service-role credentials, scoring implementation, provider integration, customer database or admin code. It is an API client only.

A failed or malformed risk check is UNKNOWN, never SAFE. Do not make irreversible payment or customer adverse decisions from unreviewed signals.
